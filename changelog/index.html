版本编号规则 按主版本、次版本和修订版本逐层查看。每个大版本从 x.1.0 开始；聊天室初版、破坏性更新和品牌与工作区重做使用 a，其余版本均使用 b。同一功能的后续修改递增修订号。

2.x功能持续扩展 · 最新 2.13.0b
2.1账户系统改版 · 最新修订 2.1.0a
2.1.0a破坏性更新
  • 注册时将唯一的登录账户名与聊天室显示用户名分开。
  • 登录、成员和消息展示改用对应字段；需要按新字段结构重建 D1 数据表。
  • 增加确认密码与注册信息校验，注册完成后可直接返回登录。
2.2个人资料与显示名 · 最新修订 2.2.0b
2.2.0b资料管理
  • 支持更改聊天室显示用户名，并同步更新历史消息与当前页面中的名称。
  • 增加“我的”资料入口和其他成员的只读资料窗口，显示头像、用户名、账户名与角色。
  • 个人资料支持修改密码与退出登录；密码更新使用现有安全哈希流程。
2.3主题与成员管理 · 最新修订 2.3.2b
2.3.0b禁言与主题
  • 增加管理员禁言功能与后端权限检查，并阻止仍在禁言期的用户发言。
  • 增加白昼 / 极夜主题切换，并记住用户的主题偏好。
  • 成员按角色排序，限制管理员之间互相禁言。
2.3.1b禁言通知与解除
  • 禁言表单增加理由；聊天室广播禁言通知，显示操作者、目标、时长和理由。
  • 增加解除禁言确认流程与解除通知；操作和通知采用一致的数据库批次处理。
  • 成员列表可直接显示“禁言”或“解除”操作状态。
2.3.2b禁言交互修正
  • 修复同一成员列表内禁言状态没有同步、解除按钮误开禁言窗口的问题。
  • 改进禁言弹窗、成员滚动条、桌面窗口尺寸与管理标签的对齐。
2.4在线状态与消息可靠性 · 最新修订 2.4.0b
2.4.0b成员在线状态
  • 聊天室显示在线人数，成员列表显示在线 / 离线状态，并定时更新在线状态。
  • 修复发送后即时刷新与轮询同时执行导致消息重复显示的问题。
  • 防止连续按 Enter 或重复提交造成重复发送。
2.5头像与系统通知 · 最新修订 2.5.1b
2.5.0b头像更新与压缩
  • 定时刷新成员头像，无需重新载入页面即可看到他人头像变化。
  • 改进头像清晰度，并压缩图片至 100 KB 以内以适配存储限制。
  • 将禁言、解除禁言通知结构化展示，突出角色、用户、操作、时长和理由。
2.5.1b角色标签与头像入口
  • 增加 AI 用户角色与 AI 管理员复合角色；AI 管理员显示“管理”和“AI”两个标签并拥有管理权限。
  • 修正角色排序、标签对齐和资料中的角色显示。
  • 调整个人资料入口：仅点击头像打开其他用户资料，昵称不再触发。
2.6语言与界面偏好 · 最新修订 2.6.0b
2.6.0b英文与本地化
  • 增加英文界面与语言偏好记忆；本地化登录注册、成员、资料、角色和管理界面。
  • 按当前语言显示消息日期，并优化角色标签在语言切换后的刷新。
  • 将主题和语言选项整理到“我的”资料窗口，并改进个人资料布局。
2.7聊天室交互 · 最新修订 2.7.1b
2.7.0b弹出动画与引用

2.7.1b引用与资料细节

  • 改进“我的”资料窗口与引用预览布局。
2.8多语言与用户提及 · 最新修订 2.8.1b
2.8.0b日文、繁体中文与 @ 用户

2.12昵称长度限制 · 最新修订 2.12.0b
2.12.0b昵称长度上限调整为 24

  • emoji 等宽字符按 2 计入；组合符号按 0 计入。
2.13用户举报与审核 · 最新修订 2.13.0b
2.13.0b人工审核与 AI 内容审核
  • 可从消息右键菜单举报其他用户的消息，并指定管理员、超管或 AI 管理员进行人工审核。
  • 被指派的审核员可在邮件收件箱中将举报标记为“违规”或“正常”；审核不会自动惩罚用户。
  • 人工审核员确认“违规”时需填写违规内容；AI 广播通知只显示接口返回的命中类别，不展示命中内容或原消息，疑似结果不作为确认违规广播。
  • 提供三个 AI 审核接口，服务端代理调用并将结果写入举报记录，不向浏览器暴露 API 密钥。
  • 新建数据库需在 D1 执行 reports-schema.sql；已部署数据库需执行相应 migration。两个极数本源接口需配置 APIZERO_API_KEY；UAPIS 接口使用无 Key 调用。
3.x品牌与界面重做、AI 工作区 · 最新 3.3.5b
3.1品牌与工作区重做 · 最新修订 3.1.0a
3.1.0a极光聊窗
  • 聊天室更名为“极光聊窗”，并采用新的侧边栏与工作区布局。
  • 新增聊天、账户与安全、外观与设置三个工作区；账户页整合头像、昵称、账户名和修改密码。
  • 外观设置提供语言切换、四种主题配色，以及每种主题均可使用的明亮 / 黑暗界面。
  • 主题包括“绚彩极光 · 青蓝星海”“深蓝幽紫 · 幻海之境”“橙霞入暮 · 藏蓝沉星”和“初音青绿 · 蔚蓝天依”，每种均由两种主题色和一种过渡色组成。
  • 为页面入场、工作区切换和侧栏选中状态增加动画；管理员导航集中显示禁言用户与待处理举报入口。
3.2讯飞星火 AI 对话与审核 · 最新修订 3.2.13b
3.2.0b接入讯飞星火
  • 新增“星火 · AI”对话工作区，接入讯飞星火 spark-x2.5-1.7b 模型，并支持连续对话与新建对话。
  • 通过 Cloudflare Pages Functions 在服务端代理模型请求；API Key 使用 XFYUN_API_KEY Secret 保存，不暴露给浏览器。
  • 优化 AI 对话界面的消息、输入区与明暗主题样式并适配窄屏；输入框不可拖动缩放，发送按钮焦点样式与主题保持一致。
  • 将 AI 入口并入原有侧边导航，桌面端和移动端均复用统一的导航按钮样式。
  • 登录响应不再返回会话令牌，继续仅通过 HttpOnly Cookie 管理登录会话。
3.2.1b思考与联网模式
  • 增加讯飞星火思考模式和联网搜索开关；开启思考模式时，分别显示浅色思考内容与正常样式的最终回答。
  • AI 请求期间锁定发送和模式切换，避免并发提交或请求参数在处理中改变。
  • 移除应用自行设置的输出 Token 上限、输入字符上限和对话截断；实际长度仍受模型上下文及服务限制。
  • 将 AI 欢迎语统一为“星火 AI”。
3.2.3bUAPIS API Key 配置
  • 接口 3 支持从 Cloudflare Pages Secret UAPIS_API_KEY 读取 Key，并通过 Bearer 认证调用；未配置时仍可使用默认调用额度。
3.2.2b新增 UAPIS 敏感词检测
  • AI 审核新增 UAPIS「敏感词检测（快速）」接口，服务端代理请求并展示违规结论与命中词。
  • AI 审核窗口分别展示极数本源和 UAPIS 服务来源标识。
  • 已部署的 D1 数据库需执行 migrations/0001-uapis-profanity-review.sql 扩展审核类型约束。
3.2.4b更新讯飞星火品牌标识
  • 将 AI 工作区名称更新为“讯飞 · 星火AI”，并在页面标题中使用讯飞星火 Logo。
  • 同步更新 AI 欢迎语、助手名称和选项的本地化文案。
3.2.5b恢复侧栏图标并调整 UAPIS 调用方式
  • 讯飞星火的侧栏图标恢复为原来的星形图标，页面标题继续使用讯飞星火 Logo。
  • AI 审核接口 3 改为无 Key 调用，不再发送 UAPIS Authorization 请求头。
3.2.6b按钮与 AI 对话界面改为纯色
  • 按钮使用主题纯色，配色预览改为青蓝、深蓝幽紫、橙藏蓝和初音绿天依蓝三色分段显示。
  • AI 对话卡片、欢迎区、发送消息和输入区域使用纯色背景，不再使用渐变。
3.2.7b调整主题主色
  • 主题一以蓝色为主色、主题二以紫色为主色；主题三橙色和主题四初音绿维持原设定。
  • 同步调整主题色变量与三色配色预览顺序。
3.2.8b星火思考模式三段选择与说明
  • 思考模式增加 Disabled、Auto、Enabled 三种状态，并将所选状态传递给讯飞星火。
  • 为思考模式和联网模式增加可悬停、可键盘聚焦的说明提示；思考提示包含无效内容时关闭思考以减少 Token 使用的说明。
3.2.9b收起 AI 思考并简化消息样式
  • 思考内容改为可折叠区；讯飞星火的思考与最终回答改为无气泡文本。
  • 思考模式和联网模式控件统一使用圆角矩形按钮。
3.2.10b统一联网模式选择样式
  • 联网模式改为与思考模式相同的分段选择样式，提供 Disabled 和 Enabled 两种状态。
3.2.11b聊天消息气泡应用主题配色
  • 自己发送的消息气泡随主题使用极光蓝、海蓝、霞橙或天依蓝。
3.2.12b统一主题气泡文字颜色
  • 四种主题的消息气泡文字统一使用白色。
3.2.13b统一界面主题色交互
  • 导航、选中态、输入焦点、提及、审核选项及 AI 工作区交互状态统一跟随当前主题配色。
  • 保留危险操作、在线状态和第三方品牌标识的语义颜色。
3.3Cloudflare Workers AI · 最新修订 3.3.5b
3.3.0b新增 Workers AI 对话工作区
  • 左侧导航新增 Cloudflare · WorkersAI 工作区，接入 @cf/meta/llama-3.2-1b-instruct 模型并支持连续对话。
  • AI 请求通过 Pages Functions 在服务端代理，不在浏览器中暴露服务凭据。
3.3.1b切换为 REST API Key 调用
  • Workers AI 改为调用 Cloudflare REST API；在 Pages 配置 CLOUDFLARE_ACCOUNT_ID 和 CLOUDFLARE_API_TOKEN，无需添加 AI 绑定。
  • Cloudflare API Token 需拥有 Workers AI Read 和 Workers AI Edit 权限。
3.3.2bWorkers AI 界面焕新
  • Workers AI 页面改为清爽简约的对话布局，加入 Cloudflare 标识、居中欢迎区和轻量消息输入框，并适配明暗主题与窄屏。
3.3.3b精简界面语言
  • 语言选项精简为简体中文和 English，移除日文与繁体中文翻译及日期格式支持；此前保存为已移除语言的偏好会回退到简体中文。
3.3.4b调整主题三、四按钮主色
  • 主题三按钮改用霞橙色，主题四按钮改用天依蓝色，并让悬停态保持对应色系。
3.3.5b修正主题四天依蓝
  • 将主题四次色、按钮、高亮、消息气泡及配色预览统一改为天依蓝 #66CCFF。
  • 按钮使用高对比深色文字，悬停色改为柔和深一阶的同色系蓝色。
